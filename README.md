# Granny Clark's Wynd Crossing Survey

MT4608 Sampling Theory group project, University of St Andrews.

**Group:** Euan Allison, Atton Cheung, Sean Gallacher, Ben Porksen-Manning, Sofia Soderberg

We counted people (including cyclists) and cars crossing Granny Clark's Wynd and estimated the weekday total between 10:00 and 16:00, using a pilot survey and a simple random sample of 21 fifteen-minute intervals.

## Files

| File | Contents |
| --- | --- |
| `analysis.R` | All the analysis: estimates, standard errors, 95% confidence intervals, sample size, Neyman allocation and figures |
| `data/pilot_counts.csv` | Pilot survey counts in 5-minute bins |
| `data/main_survey_counts.csv` | Main survey counts for each sampled interval |
| `figures/` | Plots used in the report |
